# Reading, listening and writing practice

This fallback provides basic practice coverage when no dedicated compatible skill exists. Discover current user rules and source materials before claiming specialized workflow compliance. It is not an implemented exam simulator or a replacement for official scoring descriptors.

## Reading and non-dictation listening

Use the supplied passage, link or recording at the requested scope. Retrieve referenced material when needed; preserve source identity and distinguish a transcript, summary and actual audio. If unavailable, explain the gap and continue only with supplied material.

For comprehension practice, let the learner attempt before showing answers unless guided explanation is requested. Work from overall meaning to the evidence for each answer, then useful vocabulary/collocations and inference versus explicit statement. Preserve original answers. A passage summary alone is not demonstrated comprehension.

For IELTS Reading or Listening, retain question type, numbering, exact instructions, word limits and verified matching keys. Explain an answer with source evidence; without a key label proposed answers as provisional. A transcript exercise is not an audio listening test. Use the dictation workflow for transcription attempts, correction comments or code-marked expressions.

## Writing

Distinguish a single-sentence correction, general writing, IELTS Academic Task 1, General Training Task 1 letters and Task 2 essays. For proofreading show a faithful corrected version and only important changes; optional style improvements are not errors. Do not force an essay workflow onto one sentence.

For practice, use the actual prompt and complete original attempt. Respect the learner's established mode: independent writing before a model for assessment, or model analysis → sentence back-translation → paragraph reconstruction → full writing → transfer when explicitly guided. Preserve all first attempts and revisions; label models and newly added reasoning.

For Academic Task 1 require the actual chart/map/process or task source before describing data or trends; never invent missing figures. For General Training Task 1 use the actual letter prompt, purpose, recipient, bullet points and appropriate tone; no visual is required. For Task 2 preserve the learner's position and distinguish stronger organization from new factual claims. Provide focused feedback, a faithful revision and one next action when practice is requested.

Use current official descriptors when giving detailed IELTS criterion-based feedback; clearly label estimates and their limits. A fragment or a single sentence cannot support a full essay band. Keep feedback aligned with the requested scope and do not claim progress from an assistant rewrite.

## Retention

Use English Memo only for authorized archival, preserving prompt, source, original attempts and feedback. Reading has no assumed dedicated Memo category: follow live rules or use authorized Vocabulary/other appropriate existing destinations; do not invent a database/category. Natural Sentences requires deliberate selection. Scheduling and quiz creation remain separate authorized operations.
