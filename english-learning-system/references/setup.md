# Private setup

The published toolkit contains reusable procedures, not a user's Notion page IDs, learning records, credentials, schedule, timezone or personal preferences. On first use, identify the desired workflow and the minimum settings it needs. Discover existing settings and workspace rules where authorized; ask the user for details that cannot be found reliably. Confirm destinations and authorization before writes. A URL alone is not consent to ongoing sync.

Potential settings include: feedback language and format; timezone and local memo directory; Notion Memo root and applicable rules; review database and intervals; quiz center, rules and scheduling preferences; and whether ongoing sync is enabled. Ask only what the requested operation needs. Verify page identity, parent and access, and read current rules before a write. User instructions and current rules override generic guidance. If setup is incomplete, do the work that does not depend on the missing setting and explain the limitation.

Keep private values in the user's existing private configuration or a local configuration outside the skill directory and public repository, with restrictive filesystem permissions. Reuse compatible settings (for example, the existing `~/.config/english-learner/config.json` for its supported fields) without overwriting them; store additional settings separately if needed and only with the user's agreement. Never store passwords, tokens, learning records or personal page addresses in the skill package. Do not create schedules or change host configuration as a side effect of setup.
