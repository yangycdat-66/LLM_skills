# Speaking Memo reference — Version 1.1

Use only during an explicit memo operation or the existing authorised aggregation, not after every answer. Fetch current live rules before writing; this baseline is not a substitute for newer rules. Route actual authoring through the available `english-memo` workflow and applicable Notion authoring instructions.

## Fixed review order

1. **① 今日地道语块** — Select 3–5 high-value chunks, marking the top three for practice and supported repeated items `复练`. Three columns: `语块 | 中文用途 | 当天话题例句`. Coordinate with the overall daily limit of ten expressions; do not create duplicate Natural Sentences. No filler entries.
2. **② 今日口语语法与表达问题** — Merge repeated errors into 3–5 priorities. Three columns: `我的原表达（题号/尝试） | 正确或自然表达 | 原因与下次动作`. Distinguish errors, optional naturalisation and ASR uncertainty. Leave only one next practice goal. Record progress in one evidence-backed comparison; distinguish reading, immediate imitation, independent retelling and delayed retention.
3. **③ 原答与最终润色 · 朗读/复述区** — Keep topics and all attempts in actual learning order, with concise titles and these expandable records:
   - `Question`: complete verified cue card/question; label free speech as a topic, not an invented exam question.
   - `Direct Answer｜我的原表达`: full verbatim typed answer or explicitly labelled automatic transcript, including mistakes, repetitions, mixed language, repairs and unfinished endings. Preserve each attempt; a filename, summary or source link cannot replace the text.
   - `Polished Answer｜最终朗读版`: one recommended complete, natural spoken version based on real content. Preserve previous targets in history. Label newly supplied/revised text. A full original needs a full final answer; an opening drill needs only that scope. Do not promise Band 7 or require memorisation.
   - `详细反馈与历史版本（选看）`: full correction tables, historical rewrites/models, textual assessments and limits, mistake/grammar banks, vocabulary explanations, pronunciation exercises and attempt comparisons. Do not delete verified historical content or crowd the review entrance with it.
   - One final `来源与完整性（选看）`: source inventory, dates, gaps and readback coverage. If only partially archived, show a clear warning at the start of section ③, not only inside the final toggle.

## Source and write verification

Use the existing English Memo date page and native 🎙️ icon, not a duplicate or root-level page. Assign the actual learning date in the learner’s configured timezone from source messages, including late-night material and previously missed attempts; do not infer it from edit dates. Build a complete source inventory and retain learner revisions.

Missing original content: identify the exact question/recording and what is unavailable. A memory summary is not a transcript, ASR is not reliable direct listening, and a path is not an archive. Do not infer pronunciation, actual fluency or mastery; no compulsory total band for drills or read-aloud practice. Preserve and qualify current textual estimates rather than carrying old scores forward.

If an existing topic page in the user's Part 2/3 system is in the authorised archive scope, update the original page and keep full history; the daily page still needs actual original/polished content, not links alone. Before editing, inspect the full existing content and current Notion Markdown specification. After writing, read all affected toggles and verify original beginnings/endings, polished versions, history, corrections, inventory, title, parent and icon. Report the actual verification scope. Do not create empty pages when no new learning occurred.
