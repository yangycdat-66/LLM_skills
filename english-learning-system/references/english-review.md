# Spaced review

Use the Notion connector only. Discover the existing review page, live rules, ledger, source roots, task database, schema and views. Enumerate the relevant records and nested source content; do not treat search or edit timestamps as complete inventories. Reuse the existing system, not a parallel task list.

Fixed nodes use configured intervals and timezone anchored to original learning dates. The established workflow uses D1/D3/D7/D15/D30; verify its current intervals and historical start boundary before adding tasks. Memo dates come from verified titles/content, sentence dates from Added Date. Do not invent overdue debt before the system's verified start or use catch-up dates as original dates.

Reconcile by the existing source identity, node and original due date; retain distinct source URLs unless duplication is verified. Preserve dates, notes, feedback and completed rows. For forgotten/unclear feedback, apply current extra-practice rules from actual feedback timing, not an assumed date. Combine same-source/day presentation without discarding either fixed or extra reason.

Apply live per-date sentence batching limits across fixed, overdue and extra practice; prioritize weak, deferred and old material and preserve deferred records. The established limit is five distinct sentence sources per original learning date per daily batch; Memo pages are exempt. Keep a completed same-day batch locked rather than refilling slots. Distinguish due, selected and deferred counts.

The learner supplies completion, feedback and completion dates. Partial work stays incomplete unless explicitly confirmed. A checkbox is not mastery. This workflow does not change Sentence Library Status, Review Count, Last Reviewed or Progress Log; actual sentence practice belongs to Natural Sentences. Do not rewrite the learning sources.

Preserve existing Today, Overdue, Completed and All views (or their actual names). Update only necessary date/selected-identity filters, maintaining historical visibility. Read back changed rows, filters and relevant page blocks. If enumeration is incomplete, defer affected creations and report gaps. Before retrying ambiguous writes, inspect existing identities. No new automation is implied.
