# Feedback and progress tracking

Apply the user's chosen feedback format; use the section reference if requested. Provide feedback before the substantive answer when the user has made that a standing instruction. Distinguish errors, valid alternatives and translations; do not attribute quotations or generated text to the learner.

Use settings confirmed during setup. Maintain dated local learning notes or progress records only if requested or authorized. Preserve existing content and user edits, deduplicate, and read back changes. Keep quotations and prompted practice distinct from independent use. Only describe progress when comparable dated evidence supports it; report incomplete coverage and avoid inferring fluency or pronunciation from text. No evidence means no invented entry.

If the user has authorized Notion sync, discover and verify the configured destination and live rules, inspect the whole existing target and relevant children, then incrementally merge actual learning material. Preserve edits and learner-owned status; do not create empty pages or duplicate records. Read back and report changes or failures. Do not assume that a page URL grants permission to write. Ask only for required settings that cannot be discovered reliably.

Use `english-memo` as the sole writer for authorized Vocabulary updates when coordinating through the system. Maintain the configured monthly record, evidence log and weekly synthesis only from actual learning evidence and with existing authorization; preserve originals and deduplicate. A configuration-only request produces no learning entry. Keep private logs outside this package; do not require local files for a Notion-only quiz or review workflow.
